# Ekonomické hry – kontext pro Gemini

Automaticky aktualizovaný souhrn projektu Ekonomické hry pro webové Gemini: poslední scénář s kontrolou čísel, kuchařka scenáristy, podklady scénáře, pravidla projektu a aktivní skilly. Vše v jednom souboru je `KOMPLETNI_KONTEXT.md`; po částech `00_CTI_NEJDRIV.md` až `05_AKTIVNI_SKILLY.md`. Hlavní repozitář projektu je soukromý; tenhle se přepisuje sám po každé změně (skript `scripts/kontext_pro_gemini_web.py`).
