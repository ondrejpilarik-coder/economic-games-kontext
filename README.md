# Ekonomické hry – kontext pro Gemini

Automaticky aktualizovaný souhrn projektu Ekonomické hry pro webové Gemini: poslední scénář s kontrolou čísel, kuchařka scenáristy, podklady scénáře, pravidla projektu a aktivní skilly. Začni souborem `00_CTI_NEJDRIV.md`. Každý soubor je tu jako Markdown i PDF. Hlavní repozitář projektu je soukromý; tenhle se přepisuje sám po každé změně (skript `scripts/kontext_pro_gemini_web.py`).
